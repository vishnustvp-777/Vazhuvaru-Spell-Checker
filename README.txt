# Vazhuvaru (வழுவறு) - Tamil Spell Checker - Visit this website - https://vazhuvaru.netlify.app/

Welcome to the repository for **Vazhuvaru**, a lightweight, frontend-only Tamil spell-checking engine. 

I am building this tool to help users get instant, real-time suggestions when they make spelling errors while typing in Tamil. 

### 🛠️ How it Works
Unlike heavy cloud-based AI tools, this entire spell-checker runs **locally in your browser**. It uses a custom dictionary of Tamil words and calculates the Levenshtein distance to offer the closest correct suggestions for misspelled words. There is no backend server, meaning your text is processed instantly and remains completely private.

### 🌱 The Current Focus
Because this is a rule-based dictionary engine, **this tool is only as good as the number of words it knows**. 

Right now, my primary effort is focused heavily on expanding the dataset. I am constantly manually adding new root words, common inflections, and modern Tamil terminology to the text files to make the engine smarter and more robust with every update. 

### ✨ Features
*   **Real-time Suggestions:** Click on a flagged error to see and apply the correct spelling.
*   **Fully Local execution:** No data is sent to external servers. It is built entirely with vanilla HTML, CSS, and JavaScript.
*   **Clean UI:** A simple, distraction-free interface designed purely for checking and correcting text.
